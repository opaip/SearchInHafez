# پروژه جستجوی معنایی در اشعار حافظ

این پروژه یک موتور جستجوی هوشمند برای یافتن ابیات مشابه از نظر مفهومی در دیوان حافظ است. به جای جستجوی کلمه‌به‌کلمه، این سیستم معنای عبارت ورودی شما را درک کرده و ابیات مرتبط را پیدا می‌کند.

## ✨ ویژگی‌ها

-   **جستجوی معنایی:** درک مفهوم عبارت جستجو به جای تطبیق کلمات کلیدی.
-   **مبتنی بر مدل‌های ترنسفورمر:** استفاده از مدل `paraphrase-multilingual-MiniLM-L12-v2` برای تولید بردارهای معنایی.
-   **سریع و بهینه:** ذخیره‌سازی بردارها برای جستجوهای مکرر بدون نیاز به پردازش مجدد.

## 🚀 نصب و راه‌اندازی

برای اجرای این پروژه به صورت محلی، مراحل زیر را دنبال کنید:

1.  **کلون کردن ریپازیتوری:**
    ```bash
    git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
    cd your-repo-name
    ```

2.  **نصب نیازمندی‌ها:**
    توصیه می‌شود یک محیط مجازی (virtual environment) بسازید.
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    pip install -r requirements.txt
    ```

## Usage (نحوه استفاده)

برای اجرای برنامه، اسکریپت اصلی را اجرا کنید:
```bash
python search_app.py
```
برنامه از شما یک عبارت برای جستجو می‌پرسد و ۵ بیت برتر را به همراه امتیاز شباهت نمایش می‌دهد.
